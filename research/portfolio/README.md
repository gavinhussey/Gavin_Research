# Platform-level (cross-strategy) research workspace

Reserved for analysis that spans **multiple strategies** or the
consolidated portfolio — cross-strategy correlation, capital-budget
research, signal conflicts, combined exposure, consolidated drawdown,
shared transaction costs, portfolio stress tests, strategy diversification,
portfolio-level performance.

**Do not** put Filing Momentum ML-specific (or any other single strategy's)
research here — that belongs in
`research/strategies/<strategy_id>/notebooks/`. This directory only earns
content once at least two strategies exist to compare or combine; as of
this stage (only Filing Momentum ML is registered, with no executable
implementation yet), these subdirectories are intentionally empty.
